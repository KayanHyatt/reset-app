# r.e.s.e.t — Expo (React Native) Prototype

Mental health & wellbeing prototype app for r.e.s.e.t (Expo + TypeScript) with local features (journal/logging) and Supabase for accounts + community.

---

## Prereqs (Windows)

Install:
- **Node.js** (you already have)
- **Git**
- **Expo Go** app on your phone (iOS/Android)
- **VS Code** (recommended)

Check versions:

```powershell
node -v
npm -v
git --version
